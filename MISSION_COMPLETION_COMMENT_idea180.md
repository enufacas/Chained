**Implementation**:
```python
# infrastructure/docker/adk-agents/error-observer/security_classifier.py
async def classify_error_security(error_event):
    prompt = f"""
    Analyze error for security relevance:
    Type: {error_event['error_type']}
    Message: {error_event['message']}
    
    Security issue? (yes/no)
    Type: (auth/injection/data_leak/other)
    Severity: (critical/high/medium/low)
    Action: (specific remediation steps)
    """
    return await call_gpt(prompt)
```
