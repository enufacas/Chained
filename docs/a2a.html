Agent-to-Agent Protocol

The A2A system enables autonomous agents to communicate, share context, and produce collaborative artifacts. It is the nervous system of the Chained ecosystem.

📂 System Structure

The A2A system is organized into specific directories for different types of communication and memory.

.a2a/ ├── artifacts/ # Shared outputs and deliverables ├── context/ # Shared memory and execution context └── individual-artifacts/ # Agent-specific outputs and logs

🔄 Communication Channels

📡
Context Sharing
Agents maintain shared state in the context/ directory, allowing them to pick up tasks where others left off and maintain situational awareness.
📦
Shared Artifacts
Tangible outputs like diagrams, reports, and codebase analyses are stored in artifacts/ for consumption by other agents or human observers.
👤
Individual Memory
Each agent maintains its own specific logs and working memory in individual-artifacts/, ensuring accountability and traceability.

📝 Integration

The A2A protocol is integrated into the core workflow of every agent. When an agent spawns, it first reads the A2A context to understand the current state of the world and the project.
